Pysotope

pysotope is a python package for processing isotopic data measured via GC-IRMS (δ2H, δ13C) and EA (δ13C, δ15N). Corrections for drift (time), linearity (amount), methanol (for FAME derivatization), and reference standards (e.g., VSMOW). We incorporate a number of methods for identifying coherent trends in measurement standards, enabling accurate isotopic measurements even at low concentrations.
